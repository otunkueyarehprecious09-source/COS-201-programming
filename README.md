# COS-201-programming
## Week 3: Variables, Data Types, Expressions and Input/Output

Programs are in the `week03` folder:
- SimpleCalculator.java: adds, subtracts, multiplies and divides two numbers
- AverageCalculator.java: finds the average of three numbers
- ItemCost.java: calculates total cost from price and quantity

### Compile and run
cd week03
javac SimpleCalculator.java
java SimpleCalculator

Repeat with AverageCalculator and ItemCost.
